Code Blue (NYP X IMH)

Training for critical moments, without real-world consequences.

Code Blue VR is a multiplayer virtual reality training simulator developed in collaboration between Nanyang Polytechnic (NYP) and the Institute of Mental Health (IMH).

The project aims to simulate realistic Code Blue emergency scenarios, allowing healthcare professionals to practise emergency response procedures, communication, and teamwork in an immersive virtual environment.

As part of the second development phase of this ongoing project, our team focused on establishing the core gameplay architecture and completing the end-to-end simulation workflow, while implementing as much training content as possible to support future development.

Working directly with IMH healthcare professionals, we translated real-world training requirements into interactive VR experiences.
