Game Physics In Unity

Reflections on 3D Game Physics & Simulation.

This project exposed me to a wide range of physics-based systems used in modern 3D games. Working with IK, softbody simulations, boids, player movement, and moving platforms helped me understand how physical rules and constraints shape believable interactions.

By integrating multiple systems together, I learned how important stability, tuning, and edge-case handling are in gameplay physics. The project strengthened my ability to debug complex motion and create systems that feel both responsive and natural.

Scope

  • Implementing IK systems for character movement
  • Understanding softbody behavior
  • Applying boids algorithms for group and crowd simulation

Reflections on 2D Game Physics.

This project focused on building interactive 2D systems that rely heavily on precision and stability. Implementing mesh cutting alongside player physics showed me how geometry manipulation and physics logic must work closely together.

Through testing edge cases and refining collisions, I learned how small inaccuracies can cause major gameplay issues. The project pushed me to be more careful with mathematical calculations and to design systems that remain robust under fast player movement.

Scope

  • Implementing real-time 2D mesh cutting and polygon handling
  • Managing player physics for consistent and responsive movement
