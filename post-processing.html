HLSL Shaders and Post Processing

Reflections on Post Processing And Shader Graphs.

Working on this project deepened my understanding of how post-processing effects are built and applied in a rendering pipeline. Experimenting with HLSL and Shader Graph helped me connect visual results with the underlying math and rendering concepts.

By testing and iterating on different effects, I learned how small parameter changes can drastically affect the final look. This process encouraged me to be more intentional with design choices while balancing visual style and performance.

Scope

  • Post Processing HLSL
  • Shader Graph

Reflections on Lighting & Shader Effects.

This project helped me build a deeper understanding of real-time lighting and how rendering pipelines work under the hood. Implementing forward lighting and then creating a custom deferred rendering pipeline showed me how lighting calculations and data flow differ across approaches.

By working directly with shaders and render passes, I gained more control over visual quality and performance. The process pushed me to think more technically about how light, materials, and screen-space data come together to form the final image.

Scope

  • Building and customizing a renderer pipeline for deferred rendering
  • Writing lighting and shader logic for multiple light types
